# TNEB (Tamil Nadu Electricity Board) Portal

An interactive full-stack web application built to manage and calculate TNEB electricity bills.

## 🚀 Features

* **Bill Calculator:** Calculate electricity charges based on unit consumption.
* **Responsive UI:** Built to work smoothly on mobile, tablet, and desktop devices.
* **Fast Performance:** Powered by Vite and React for quick page loading and minimal bundling size.
* **Robust Backend:** Secure backend APIs managed with Spring Boot and database management via MySQL.

## 🛠️ Tech Stack

* **Frontend:** [React](https://react.dev/), [Vite](https://vitejs.dev/)
* **Backend:** Spring Boot (Java)
* **Database & Tools:** MySQL, MySQL Workbench
